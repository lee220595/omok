# 오목 프로젝트 0.1.0 — 개발용 로컬 대국

Windows 10·11 64비트용 개발 중인 프로그램입니다. ZIP 전체를 풀고 omok.exe를 실행하세요. 별도 컴파일러·CMake·Ninja 설치는 필요하지 않습니다. 실제 GUI 대국의 수동 검증이 남아 완성본으로 소개하지 않습니다.

1. 개발 확인용 준비 배치와 흑/백 참가자 배정을 선택하고 시작합니다. 기본 3수에서는 백 차례입니다. 모든 제공 배치는 자체 작성했으며 공식 대회 오프닝이 아닙니다.
2. 교차점을 클릭하면 즉시 착수합니다. 오른쪽에 차례·수순·마지막 수·결과를 표시합니다. 흑 금수 착수는 반칙패로 종료합니다. 끝난 대국에는 추가 착수할 수 없습니다.
3. 현재 차례 기권과 동일 준비 배치로 재시작을 제공합니다. 금수 표시는 기본 켬이며 흑 차례에 붉은 X로 표시합니다.
4. compact 입력은 열 a..o와 행 1..15의 순서열(예: h8i8g9)입니다. 잘못된 배치로 시작을 요청하면 진행 중 대국을 보존하고 오류를 표시합니다.

창의 닫기(X) 또는 Alt+F4로 정상 종료합니다. 재빌드하거나 실행 파일을 교체하기 전에 프로그램을 닫으세요. 종료 시 금수 작업자가 현재 후보 판정을 마칠 때까지 기다릴 수 있습니다. 최악 대기 시간은 미검증입니다.

시계·자원 제한 강제, Swap2 GUI/규칙 연결, AI 통신/대국, 기보 파일/복기, 자체 AI는 미구현입니다. 이 패키지는 대회 설정 전체를 준수하는 프로그램이나 Gomocup 제출 엔진이 아닙니다.

배포 고지와 licenses 폴더를 함께 유지하세요. MinGW GCC·winpthreads 런타임은 정적 링크하며 Windows 기본 DLL은 배포하지 않습니다. 외부 매니저·AI·모델도 포함하지 않습니다.

소스 루트 README.md와 docs/verification-match.md에 빌드·검증·남은 수동 절차가 있습니다. 이 실행 패키지에는 소스·테스트 실행 파일을 넣지 않습니다. 개발 도구 없는 별도 Windows 10·11 환경은 미검증입니다.

# 오목 프로젝트 0.1.0 — 로컬 대국·외부 Rapfi 연결

Windows10·11 64비트용 개발 프로그램입니다. ZIP 전체를 풀고 omok.exe를 실행하세요. 컴파일러/CMake/Ninja는 실행에 필요하지 않습니다. 대회 설정 전체 준수·완성본은 아닙니다.

초기 선택인 [처음부터 · 빈 보드 (렌주)]에서 [대국 시작]을 누르면0수·흑 선공으로 시작합니다. 실행 직후에는 시작 대기이므로 먼저 버튼을 누르세요. 교차점 클릭 즉시 착수·자동 교대합니다. 재시작은 원래 시작 방식으로 돌아갑니다. 가장자리에서는 격자선 안쪽을 클릭하세요. 흑 금수는 반칙패로 종료합니다. 기권·금수 표시(기본 켬)도 제공합니다. 개발용 준비 배치를 선택하면 배치에서 이어 둘 수도 있습니다. 빈 보드 모드는 렌주 보드 판정과200수 종료를 사용하며 정식 대회 오프닝 절차는 아닙니다. 공식 준비 데이터는 포함하지 않습니다.

대국 방식은 로컬 사람 대 사람, Rapfi A/사람 B, 사람 A/Rapfi B입니다. **Rapfi exe·config.toml·가중치는 별도 준비**해야 합니다. 프로젝트의 external/rapfi/Rapfi-engine 위치를 자동 탐색하며, 다른 곳이면 Rapfi 경로에 exe 전체 경로를 입력하세요. CPU에 맞는 Windows AVX2/SSE 파일을 사용하고 coord_conversion_mode="none"을 유지합니다. AI 차례에는 사람 클릭을 받지 않습니다. “사람 기권”은 AI 사고 중에도 사용할 수 있습니다.

흑A/백B에서 [사람 A / Rapfi B]는 사람이 흑 선공, [Rapfi A / 사람 B]는 Rapfi가 흑 선공입니다. 흑B/백A로 바꾸면 선후공이 반대가 됩니다.

외부 엔진은 별도 프로세스이며 매 수 새로 실행합니다. 빈 보드 첫 수는BEGIN, 이후는 수순 순서의BOARD 복원 후 종료합니다. AI 한 수30초·누적180초, 프로세스1GiB/한 논리CPU를 제한합니다. TT/모델 여유를 위해 엔진 예산은512MiB와 남은 검색 시간보다 작게 전달합니다. 사람 시계는 없으며 전체 대회 정책 검증과 구분합니다. 로그는 실행 파일 옆 logs/engine-*.log입니다.

닫기(X)/Alt+F4로 정상 종료합니다. 종료 시 엔진에 END를 보내고 기다린 뒤 필요한 경우 이 프로그램이 생성한 엔진만 정리합니다. 재시작·기권·닫기 후 이전 응답을 새 대국에 적용하지 않습니다. 실행 파일 교체 전 창을 닫으세요.

AI 대 AI·Swap2 GUI/규칙 연결·기보 파일/복기·자체 AI는 미구현입니다. 전체 대국·오류·리사이즈·깨끗한 Windows10/11 환경의 검증이 남아 있습니다. 배포 고지와 licenses 폴더를 유지하세요. Rapfi·모델·외부 매니저는 이 패키지에 포함하지 않습니다. 자세한 설치/검증은 소스 프로젝트 README와 docs/rapfi-integration.md, docs/verification-rapfi.md에 있습니다.

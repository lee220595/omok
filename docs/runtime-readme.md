# 오목 프로젝트 0.1.0 — 기본 창

Windows 10·11 64비트용 개발 중인 프로그램입니다. ZIP 전체를 풀고 omok.exe를 실행하세요. 별도 컴파일러·CMake·Ninja 설치는 필요하지 않습니다.

현재 기능은 기본 GUI 창과 한글 안내 표시뿐입니다. 게임·렌주 판정·기보·AI 기능은 아직 제공하지 않습니다. 창의 닫기(X) 또는 Alt+F4로 종료합니다. 재빌드하거나 실행 파일을 교체할 때는 먼저 프로그램을 닫으세요.

배포 고지와 licenses 폴더를 함께 유지하세요. 외부 매니저·AI·모델은 포함하지 않습니다. 이 패키지는 Gomocup 제출 엔진이 아닙니다.

빌드 방법과 계획은 소스 프로젝트 루트의 README.md에 있습니다. 이 실행 패키지에는 소스·빌드 스크립트를 포함하지 않습니다. 개발 도구 없는 별도 Windows 10·11 환경의 최종 검증은 아직 진행하지 않았습니다.

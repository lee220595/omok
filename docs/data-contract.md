# 원본·정규화 기록·학습 샘플 계약

2026-10-28 설계. **최소 JSON trace 저장/재생은 [Python 환경](python-headless.md), 권리 manifest→재생 검증→샘플/대국·D4 그룹 분할은 [지도학습 구현](supervised-learning.md)에 기능 검증했다. 외부 기보 형식 파서·실제 권리 확인 학습 데이터셋은 미구현/미확보**이다. 저장 인코딩 선택은 [결정 목록](requirements-pending.md)을 따른다. 기존 [오프닝 이벤트](opening-contract.md)·[match 결과](match-contract.md)를 복제하지 않고 보존한다.

## 세 층과 변환 계보

| 층 | 필수 의미 |
|---|---|
| 원본 기보/자료 | 원본 바이트/해시·출처/제공자·버전/취득 시점·이용 조건 근거·원본 ID. 불완전/결과 불명도 보존 |
| 정규화 대국 기록 | schema/파서/정규화 버전·부모 원본 ID/구간·대국 ID·규칙/종료/시작 프로필·실제 순서/좌표/색/actor·배정/교환/선택 이벤트·최종 결과/근거·실행 상태/종료 사유·검증/필터 사유 |
| 학습 샘플 | sample/schema/전처리/encoder/행동/가치/라벨 정책 버전·부모 대국/국면 ID·착수 전 관점/마스크·정책/가치 목표와 각 자격/손실 가중 여부·분할/증강 ID·모델/탐색 계보 |

각 단계는 입력 ID/해시·변환 코드/설정/버전·출력 ID·검사 결과·제외/격리 이유를 manifest로 남긴다. 원본을 수정해 정상 자료처럼 덮어쓰지 않는다. 단순 파일 위치를 안정적인 원본 식별자로 쓰지 않는다. 이용 조건이 불명확하면 미허용/보류로 관리하고 학습/모델 공개/재배포 허가를 추정하지 않는다.

Rapfi 평가 기록은 별도 평가 계보이며 현재 계획에서는 정책/가치 정답이나 자기 대국 경험으로 전환하지 않는다. 수동 사람 대 Rapfi 기록도 자동 학습 자료가 아니다.

## 종료 사실과 결과의 신뢰도

원본이 주장하는 결과, 정규화 검증 결과, 학습 자격은 별개다. 다음 사건을 다른 코드/필드로 구분하고 winner/draw의 출처·확인 여부를 보존한다.

- 보드 승리, 프로필 수순/만판 무승부, 규칙상 금수패.
- 기권, 확인된 합의 무승부, 시간패/불법 응답 등 운영상 패배.
- 기록이 중간에서 끝남, 결과 주장 없음/확인 불가, 파일/수순 손상.
- 실행 취소/임의 길이 제한/프로세스 오류/시작 실패/판정 충돌·무효.

기권/시간패는5목 부재만으로 손상 기보가 아니다. 합의 무승부가 원본에 있어도 현재 live match가 이를 지원하는 것은 아니다. 해당 프로필에서 허용/확인됐는지 검증하고 미확인이면 주장만 보존한다. 결과 불명·중단을 빈 winner=draw로 채우지 않는다. 성공 수순 뒤 금수 시도가 있었다면 그 시도는 종료 이벤트이며 성공 배치 목록에 돌을 더하지 않는다.

## 관점·오프닝과 재생

정규화 기록은 참가자 식별자와 초기/최종 색 배정, 시간 순서의 배정/교환 이벤트를 보존한다. 실제 각 일반 착수 직전의 actor/색/관점을 재생으로 구한다. 최종 winner를 고정 흑 winner로 미리 변환해 과거 색 선택 전 상태에 일괄 적용하지 않는다. 임의의 대국 중 색 변경은 해당 규칙/이벤트 계약이 없으면 격리한다.

준비 돌의 placed_by 없음, Swap2 제안/추가 배치·색 선택, 본게임 일반 착수는 다른 이벤트다. 초기 v1 정책·가치 샘플은 **색이 배정되고 RenjuReady인 일반 대국 국면**만 사용한다. 제안/선택 이벤트를225개 일반 착수 정답으로 만들지 않는다. 준비 돌도 프로필의 총 배치 수에는 포함한다. 이미 종료된 시작 배치는 재생/결과 시험에는 사용해도 일반 다음 수 샘플을 생성하지 않는다.

## 정책/가치 목표를 따로 판정

공통 선행 조건은 권리 확인·지원 규칙/프로필 식별·관점/상태 재생 성공·부모 계보·분할 정책 준수·Rapfi 평가 데이터가 아님이다. 각 샘플은 policy_eligible/value_eligible과 사유를 따로 저장하고 미정 목표를 수치0으로 채우지 않는다.

정책 자격: 착수 전 유효한 일반 대국 상태, 실제 기록된 일반 수가 같은 rules 마스크에서 합법, 행동/색/actor 일치. 지도학습은 해당 행동의 정답, 자기 대국은 버전이 기록된 MCTS 합법 방문 분포를 사용한다. 금수 시도·기권·색 선택은 정책 정답이 아니다. 재생에서 불법/오류를 발견하면 임의 교정/질량 재분배하지 않는다.

가치 자격: 위 공통 조건에 더해 확인된 최종 결과와 **해당 종료 사유를 허용하는 라벨 정책**이 필요하다. 국면의 현재 착수자를 기준으로 승/무/패 +1/0/-1을 부여한다([환경 결과 전파](headless-environment-contract.md)). 정책 자격과 독립적이므로 실제 다음 일반 수가 없는 기권 직전 국면 등은 별도 가치 전용 후보일 수 있지만 아래 기본 정책을 따른다.

초기 라벨 정책 `board-outcome-v1`은 보드 승리/지원 프로필의 정상 무승부만 가치 정답으로 허용하고, 운영/선택 종료의 추가 사용은 별도 정책 버전으로 검토한다. 이는 보존된 기권/금수패 결과를 무효로 바꾸는 제품 규칙이 아니다.

| 기록 상태 | 정책 샘플 | 가치 샘플 |
|---|---|---|
| 검증된 보드 승리/규칙 무승부 | 위 정책 자격을 만족하는 일반 수 | v1에서 적격한 착수 전 국면. 정상 draw만0 |
| 정상적으로 해석되는 미완료 기보·결과 불명 | 검증된 합법 prefix는 정책 전용 가능, incomplete 사유 기록 | 없음 |
| 확인된 기권/금수패/합의 무승부 | 검증된 앞선 일반 수는 가능, 종료 동작/금수 시도는 제외 | v1에서는 보류. 포함/가중 기준은 다음 라벨 정책 결정 전 자동 생성하지 않음 |
| 시간패·프로세스/응답 오류·취소/임의 제한·무효 | 기본 격리. 검증 prefix를 쓸 정책을 추후 승인/버전으로 명시하기 전 제외 | 없음. 대회 결과를 정상 보상으로 전용하지 않음 |
| 수순/형식 손상·지원 규칙/권리 불명·관점 불명 | 검증/권리 해소 전 격리 | 없음 |
| Rapfi 벤치마크 대국 | 평가 기록만 보존, 학습 제외 | 학습 제외 |

정책 전용/가치 전용 샘플은 별도 target_present/손실 마스크로 처리한다. 누락된 정책을 임의 행동으로, 누락된 가치를 draw0으로 보간하지 않는다. 손실 계수·비율/가중치·기권/금수 등 추가 라벨 정책은 지도학습/강화학습 착수 전에 근거를 정한다.

## 분할과 증강·남은 중복

대국/원본 계보와 전체 대국의 회전/반사 중복 그룹을 먼저 만들고 **대국 그룹 단위로 학습/검증/평가를 분리한 뒤 증강**한다. 변환은 [모델 D4 계약](model-contract.md)을 사용하며 관측/행동/마스크를 함께 보낸다. 분할 seed·대국/그룹 목록·중복/증강 알고리즘/버전은 고정 manifest로 남긴다.

국면 단위 분할 누출도 검사한다. 정확 일치 키는 대칭 정규화 보드만이 아니라 착수 색·지원 프로필/남은 수순·단계/관점도 포함한다. 유사 국면은 사전에 정한 동일 prefix/돌 차이 등 기준으로 점검한다. 반복된 중반/후반 국면은 대국 재배치/격리 등을 검토한다. 공통 오프닝을 모두 묶으면 대부분 대국이 한 그룹이 될 수 있으므로, 제거하지 못한 공통 prefix·정확/유사 중복의 수/비율·수순 구간·허용 이유/한계를 보고한다. 조용히 누출0이라고 주장하지 않는다.

유사성 기준/공통 오프닝 허용 경계는 P2 전 결정한다. 선택지는 완전 격리 또는 선언된 공통 prefix 예외다. 초기 권장안은 전체 대국 중복은 완전 그룹 격리하고, 국면은 정확 일치+명시적 유사 기준을 검사해 공통 오프닝 잔여 범위를 별도 공개하는 방식이다. 평가 결과를 본 뒤 분할/허용 경계를 바꾸지 않는다.

## 완료 기준

원본→정규화→샘플의 계보/필터 사유 추적과 최소 기록의 왕복 재생을 검증한다. 불완전/기권/시간패/합의/미확인 결과를 구분하고 정책 전용/가치 보류·Rapfi 제외·오프닝/색 관점·마스크/정답 불일치 격리를 시험한다. 대국/대칭 중복과 동일·유사 국면의 분할 간 통계를 내며 증강 후 누출도 검사한다. 원본 권리·프로필·라벨 정책이 미정이면 해당 데이터 사용을 보류하고 데이터셋 전체 완료로 표시하지 않는다.

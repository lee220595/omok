# 정책·가치 모델 입출력과 체크포인트 계약

2026-10-28 설계 계약 v1. **공통 정책·가치 CNN/체크포인트/SL 재개·RL 초기 가중치 로드는 [지도학습 구현](supervised-learning.md)에 기능 검증했다.** 관측 float32 인코더는 [Python 환경](python-headless.md)에 있다. MCTS/RL 업데이트·제출 런타임은 미구현이다. 아래는 공통 의미 정의이며 실제 구현된 API·파일 형식·명령은 지도학습 안내에서 구분한다. 현재 CPU 검증은 PyTorch2.14.1+cpu·작은 CNN을 선정했고 최종 모델 크기·제출 추론 런타임은 [결정 목록](requirements-pending.md)에 남긴다.

## 같은 모델을 두 학습 단계에서 사용

정책·가치 신경망을 지도학습과 자기 대국 강화학습에서 재사용한다. 지도학습 가중치를 강화학습 초기 모델로 읽어 이어 학습해야 한다. 두 단계는 인코더·행동 공간·마스크·가치 관점·직렬화 메타데이터 계약을 공유한다. 지도학습 기보 전처리와 자기 대국 경험 생성기는 별도 파이프라인이며, 공통 샘플 경계에서 합류한다([데이터 계약](data-contract.md)). 입력/헤드 의미를 바꾸면 새 계약 버전과 명시적 변환/재검증이 필요하다.

## 초기 관측 계약: renju15-observation-v1

지원 범위는 현재15×15 렌주의 **일반 대국·유효한 색 배정·총200수 프로필**이다. DirectRenju와 복원 완료 PreparedRenju를 지원 대상으로 설계하되 오프닝 제안/색 선택 중·RuleContractRequired에는 모델을 호출하지 않는다. 200수는 이 버전의 지원 프로필 조건이며 모든 학습/대회의 상수가 아니다. 다른 종료 정책은 호환성 확인과 새 지원 계약 없이 받지 않는다.

입력은 float32, NCHW 순서 `[batch, 4, 15, 15]`로 정의한다. 보드 좌표는 기존 [상태 계약](state-model.md)을 재사용한다.

| 채널 | 값/의미 |
|---|---|
| 0: 내 돌 | 현재 착수자 색의 돌1, 나머지0 |
| 1: 상대 돌 | 반대 색 돌1, 나머지0. 빈칸은 두 채널 모두0 |
| 2: 착수자 흑 여부 | 현재 색이 흑이면 전 칸1, 백이면0. A/B 식별자나 엔진 own 숫자와 다름 |
| 3: 남은 규칙 수순 비율 | 전 칸 `(L-n)/L`, 지원 프로필에서 L=200, n=준비 배치를 포함한 성공 배치 수 |

n/L/차례·색 배정·프로필이 일관되는지 검사한다. 범위를 벗어나면 잘라서 정상화하지 않고 상태/프로필 오류로 반환한다. 양자화·저정밀도 내보내기는 이후 오차/합법 대국 검증과 별도 아티팩트 메타데이터로 관리한다.

### 보드만으로 충분하지 않은 정보

현재 state는 돌을 제거하지 않아 보드 점유 수와 성공 이력 길이가 일치한다. 따라서 현재 n 자체는 점유 수로 재구성할 수 있지만, 준비 돌도 센다는 의미와 프로필의 L을 명시해 위 채널로 전달한다. 금수 시도는 성공 배치가 아니므로 n을 늘리지 않는다.

현재 색/참가자·색 소유·오프닝 단계·종료/중단 사유·이력의 순서/배치 주체·프로필·Token은 보드만으로 일반적으로 복원할 수 없다. 관측 응답은 텐서 외에 이 메타데이터와 절대색 보드/현재 상태를 보존한다([환경 계약](headless-environment-contract.md)). 색/차례와 수순 채널 이외의 메타데이터를 텐서에 몰래 추가하지 않는다. 동일 보드라도 기권/시간패/중단 여부가 다를 수 있다.

이 v1 모델의 가치는 규칙에 따른 보드 대국 결과 관점이다. 시계는 실행기/엔진의 제한 관리 메타데이터이며 시간패를 시간 입력 없는 보드 가치 정답으로 자동 사용하지 않는다. 시계/오프닝 선택까지 평가하는 모델을 도입하려면 관측/가치/라벨 계약을 개정한다.

## 행동·정책·마스크

- 행동은225개 교차점뿐이다. `a = row*15 + column`, 역변환은 `row=a/15`의 정수 몫, `column=a%15`. A1=0, O1=14, A15=210, O15=224다. 패스·기권·색 선택은 이 행동 공간에 없다.
- 정책의 원시 출력은 float32 logits `[batch,225]`다. 모든 출력이 유한한지 검사한다. 합법 마스크는 bool225개이며 [환경 계약](headless-environment-contract.md)의 같은 판정/Token에서 얻는다.
- 마스크가 참인 logits에만 안정적인 softmax를 적용한다: 합법 원소 최대를 빼고 지수화/합으로 나눈다. 불법 행동 확률은0, 합법 확률 합은1이다. 단순히 보드 빈칸만을 합법으로 취급하지 않는다.
- 지도학습의 합법 착수 정답과 자기 대국의 합법 MCTS 방문 분포는 같은225개 순서를 사용한다. 불법 행동에 정답 질량이 있으면 임의 재분배하지 않고 샘플/생성기 오류로 격리한다.
- NaN/Inf·형상 불일치·정규화 실패는 추론 오류다. 기본 동작에서 균등 분포로 조용히 대체하지 않는다. 진단용 대체가 필요하면 별도 설정/로그와 무효 평가 표시를 먼저 정의한다.

## 가치·종료·MCTS 관점

가치 출력은 float32 `[batch,1]`, 범위[-1,1], **그 국면에서 현재 착수할 색/참가자 기준**이다. 적격한 최종 승/무/패 목표는 +1/0/-1이며, 적격 여부는 [환경의 결과 전파](headless-environment-contract.md)·[데이터의 정답 자격](data-contract.md)을 따른다. 고정 흑 관점이나 항상 참가자A 관점으로 해석하지 않는다.

공통 추론 경계는 모델/입출력/프로필 버전과 스냅샷 ID/Token, 관측/마스크를 받아 같은 식별자와 logits/value 또는 명시적 오류를 반환한다. 추론이 원본 환경을 변경하지 않으며 적용 시 Token을 다시 확인한다. 가치의 NaN/Inf·범위 이탈도 오류로 처리하고 임의로 잘라 정상 출력으로 바꾸지 않는다. 실제 함수/전송 API·허용 수치 오차는 도구 선정 후 명세한다.

| 상태 | 처리 |
|---|---|
| 정상 진행·합법 행동 있음 | 텐서/정책/가치를 생성하고 합법 행동만 선택 |
| 규칙상 종료 | 마스크0, 모델/MCTS 확장 금지. 종료 후 next_color가 없으므로 신경망 관점을 임의 생성하지 않음 |
| 실행상 중단/취소 | 모델/학습 결과를 정상 승무패로 생성하지 않음 |
| 일반 대국인데 합법 행동0 | BlockedNoLegalAction 진단. 승패/무승부/패스를 만들지 않고 실행/가치 샘플 보류. 규칙상 최종 처리 결정은 미정 목록으로 추적 |
| 오프닝 입력/규칙 연결 미확정 | 일반 대국 모델 입력 불가. 별도 오프닝 의미를225개 착수로 대체하지 않음 |

MCTS의 node에는 해당 시점의 착수자 관점을 보존하고 edge Q는 부모 착수자 기준으로 저장한다. 비종료 leaf의 v를 상위로 전파할 때 일반 대국의 실제 차례 교대마다 부호를 반전한다. 준비 배치 길이/데이터셋 샘플 번호의 홀짝으로 관점을 추정하지 않는다. 이 v1 트리는 오프닝 색 선택 전환을 탐색하지 않는다.

종료 leaf는 신경망을 호출하지 않고 확인된 winner/draw를 **각 상위 node의 보존된 착수자**와 비교해 +1/0/-1로 계산한다. 이미 부모 관점으로 바꾼 결과를 다시 반전하지 않는다. 예: 흑의 승리 수는 부모 흑 node에+1, 그 전 백 node에-1이다. 금수는 마스크로 탐색에서 제외하되 실제 금수패 기록의 결과는 별도 의미로 보존한다. 중단/blocked를 terminal0으로 backup하지 않는다.

## 회전·반사

정사각 보드의8개 변환은 `R(r,c)=(c,14-r)`, `F(r,c)=(r,14-c)`로 두고 `{R^k, R^k∘F | k=0..3}`로 정의한다. 합성은 F를 먼저 적용하고 R을 k회 적용한다. 관측의 공간 채널·행동 좌표/인덱스·정책 정답/분포·합법 마스크를 같은 변환으로 보낸다. 착수자 색/남은 수순 상수 채널과 가치 부호는 바꾸지 않는다. 증강 때 색을 교환하지 않는다. 추론에서 변환을 썼으면 정책을 역변환해 원래 좌표로 적용한다. 합성/역변환·모서리·마스크와 기존 회전/대칭 판정의 일치를 시험한다. 분할 후에만 증강한다.

## 저장·재개·단계 전환

| 목적/논리 아티팩트 | 복원 규칙 |
|---|---|
| 추론용 모델 | 가중치/추론 그래프와 입출력·지원 프로필 manifest만 필요. optimizer 등 학습 재개 상태를 포함했다고 가정하지 않음 |
| 같은 단계 학습 재개 | 가중치, optimizer, scheduler, 사용 시 AMP scaler, 단계/epoch/step, RNG, sampler/데이터 cursor·분할, 설정을 함께 복원. 누락이면 정확한 재개가 아니며 명시적 새 실행으로만 처리 |
| SL→RL 다음 단계 초기화 | 같은 모델/입출력 계약의 지도학습 가중치를 초기화에 재사용. **optimizer/scheduler/scaler·RL step/경험 저장소는 기본적으로 새로 초기화**, 부모 체크포인트/전환 모드 기록. SL 상태를 무조건 동일 복원하지 않음 |
| RL 같은 단계 재개 | 위 학습 상태와 경험 저장소/큐의 ID·버전/진행 위치·자기 대국 모델/설정·완료 대국 목록을 복원. 실행 중이던 미완료 대국은 재개/재실행 정책으로 처리하고 완료 라벨을 만들지 않음 |

단계 전환 때 optimizer를 유지하는 실험은 별도 전환 설정·호환성 근거·비교 실험으로만 허용하며 기본 재개와 혼합하지 않는다. 추론 파일을 학습 재개 체크포인트로 자동 판별/오인하지 않는다. 저장 중 중단된 부분 파일은 완료 manifest로 게시하지 않는다.

필수 메타데이터: schema/artifact_kind·단계/전환 모드·모델 ID/구조 설정과 해시·관측/행동/마스크/가치 계약 ID·dtype/layout·지원 규칙/종료 프로필 ID/버전·코드/데이터/전처리/분할 버전·시드/RNG와 재현 범위·학습 설정/진행·부모 체크포인트·내용 해시·프레임워크/내보내기 도구 버전. 데이터 없는 단계도 해당 없음을 명시한다. 추론/재개별 필수 상태가 다른 것은 명시적 schema로 구분한다.

로더는 키/형상/계약/프로필·해시/상태 완전성을 검사해 불일치 시 실패한다. 알 수 없는 버전을 임의 기본값으로 채우거나 일부 가중치만 조용히 읽지 않는다. 코드 커밋이 다르면 지원 선언/검증된 이행 여부를 확인하고 기록한다. 실험적 이행은 새 ID/변환 기록·전후 예측 비교를 남긴다. 실제 바이너리 저장 형식·추론 런타임·허용 수치 오차는 도구 선정 단계에서 결정한다.

## 완료 기준

SL 체크포인트→RL 초기 모델이 같은 입력에서 전환 직전 예측을 재현하는지, 단계 전환 시 학습 상태가 지정대로 초기화되는지, 같은 단계 재개 시 진행 상태가 복원되는지 시험한다. 인덱스/관점/수순 입력·마스크/softmax·D4 역변환·MCTS 부호/종료·불일치 체크포인트 거부를 고정 사례로 검증한다. 비결정적 실행의 수치 허용 범위는 기록하며 체크포인트 로딩 성공을 학습/실력 성공으로 보고하지 않는다.

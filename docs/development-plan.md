## 의존성과 미정 범위

- P1~P7은 기존15×15 렌주 일반 대국 경로로 진행할 수 있다. 목표 리그와 무관한 GUI 편의/클린 GUI 배포·Swap2 미해결·공식 준비 데이터 미확보가 전체 학습 개발의 자동 차단 조건은 아니다. 자체 fixture는 공식 데이터로 소개하지 않는다.
- Swap2는 별도 호환성 요구로 남기고 RuleContractRequired를 우회하지 않는다. 목표 리그의 필수 여부는 P8의 공식 대상 확인과 구분한다. 기존 매니저 활용/버전 검증 요구도 유지한다.
- 현재200수/시간/자원/오프닝은 당시 잠정 프로필의 고정 구현이다. 학습 실행기의 임의 cap과 정상 무승부를 혼합하지 않는다. 다른 프로필은 지원/관측 계약 검증 없이 이름만 바꿔 사용하지 않는다.
- 모델 입출력 v1·SL/RL 연결·기본 재개 의미·기본 데이터 라벨 자격·평가 점수/구간 의미는 상세 계약에 정의한다. 모델 크기/블록 수·도구/장비·실제 저장 인코딩·오류/비보드 결과 추가 학습·유사 국면 경계·실력 목표/공식 리그는 결정 목록에 시점/선택지를 둔다.

## 확장/교체와 회귀

AI 외 상태·규칙·오프닝·대국 제어·외부 통신·기보/데이터 입출력·평가 실행기·GUI·설정/로그/배포는 작은 책임/교체 경계를 둔다. GUI/OS/특정 엔진 의존성은 어댑터에 모으고 새 형식/실행/엔진이 핵심 판정을 광범위하게 바꾸지 않게 한다. 공개 인터페이스/저장 형식의 버전/호환성과 관련 회귀를 각 단계 산출물로 남긴다. 프로필을 여러 모듈에 새로 중복 하드코딩하지 않는다. AI 내부의 최소 구조 원칙도 공통 모델/체크포인트/데이터/추론 계약의 예외는 아니다.

예상만으로 플러그인/과도한 추상화를 도입하거나 이 원칙만으로 기존 코드를 재작성하지 않는다. 기존 고정값/경계의 개선은 필요한 작업에서 근거·영향·회귀로 단계적으로 수행한다. 다른 규칙·보드 크기·온라인 등 미승인 기능을 선행 구현하지 않는다.

## P1 구현 결과와 다음 작업 하나

2026-10-28 사용자 명시 승인으로 P1을 Python 반복 대국까지 구현했다. 선택적 ctypes DLL, 독립 복제/관측/마스크/Token, ordered/random·흑백 교대·시드·완료 단위 재개, JSON trace 안전 저장/독립 재생과 오류/중단 분리를 제공한다. [실제 명령·계약·검증·처리량](python-headless.md)을 따른다. 기존 코어 판정/GUI/외부 엔진 코드는 변경하지 않았다. 합법 수0은 blocked로 격리하고 draw를 추가하지 않는다.

## P2/P3 및 P4의 추론 대국 기능 검증

후속 사용자 승인으로 권리 manifest/trace 재생→샘플/대국·D4 그룹 분리→작은 PyTorch CNN 지도학습→추론/SL 재개 체크포인트→모델 플레이어/완결 대국·기록 재생을 구현했다. 자체10판95샘플(6/2/2판·58/18/19샘플)과 별도 단일 샘플 과적합으로 기능을 검증했다. [실제 명령/한계](supervised-learning.md)·[검증 JSON](verification/supervised-learning.json)을 따른다.

P2 전체(외부 기보/권리·형식 파서·엄격 누출 제거/실제 자료)는 미완료다. P3도 실제 고수 기보 SL 성능/실력 향상은 미검증이다. P4는 Python 저장 모델 합법 대국만 검증했으며 Gomocup 수신기/패키징은 미구현이다. 따라서 단계 전체나 최종 제출 적합성을 완료 처리하지 않는다.

**다음 작업 하나는 정책·가치 모델에 MCTS 연결**이다. 현재 모델은 기능 검증용이며 실력 향상 주장을 하지 않는다. 탐색 관점·종료/blocked·합법 마스크·고정 예산/모델 단독 비교를 별도 범위로 다루고 이번에는 자동 시작하지 않는다. RL/대량 평가·프로토콜·GUI·다른 규칙은 다음 작업의 자동 승인도 아니다.

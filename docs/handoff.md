# 오목 프로젝트 개발 인계

갱신일: 2026-10-28 후속 확정 반영. 이번 작업은 **기본 AI 경로·Rapfi 평가 전용 역할·AI 외 확장성 원칙의 문서 정리**만 수행했다. 모델 학습·새 기능·코드 재구성·의존성 설치/추가·제출은 시작하지 않았다.

## 목표와 현재 우선순위

최종 목표는 지도학습과 강화학습을 기반으로 강력한 자체 오목 AI를 개발하고 Gomocup에서 실행·대국할 독립 엔진으로 완성하는 것이다. 주 산출물은 자체 모델·추론/탐색 엔진·소스/실행 파일·재현 가능한 검증 자료다. 규칙 정확성 → 자동 대국/데이터 → 정책·가치 신경망 지도학습 → MCTS 결합 → 자기 대국 강화학습 → 평가/제출 검증 순이며 프로토콜 최소 수신 검증은 초기에 병행/회귀한다.

Rapfi는 고정 외부 벤치마크로 중간/최종 평가에만 사용하고 현재 계획에서는 학습 상대·정답 생성 교사로 사용하지 않는다. 이전 자체 모델·단순 기준 플레이어·Rapfi를 구분하고 같은 배치에서 흑백 교대·버전/설정/시드/자원 조건을 기록한다. AI 자체는 최소 구조부터 실험/측정으로 발전시키고, AI 외 모든 기능에는 작은 교체 경계·프로필·데이터/공개 인터페이스 버전·관련 회귀 원칙을 적용한다.

GUI는 관찰/분석 보조 도구다. GUI 편의 기능 전체·클린 Windows GUI 배포·외부 연동 전체 완료를 학습 착수의 선행 조건으로 두지 않는다. 기존 미검증을 완료 처리하지도 않는다. [AGENTS](../AGENTS.md)·[개발 계획](development-plan.md)·[학습/데이터/평가 원칙](learning-and-evaluation.md)·[승인/미정 사항](requirements-pending.md)을 우선 읽는다.

DirectRenju/자체 준비 fixture로 확인하며 공식 데이터/Rapfi/GPU/학습 프레임워크가 필수는 아니다. 작은 어댑터·버전/호환 범위를 명시한 공개 인터페이스와 관련 회귀를 산출물로 한다. 준비/종료/RuleContractRequired·Token/거부 시 전체 보존·행열/색/참가자를 검증하고 기본 빌드를 유지한다. 반복/병렬 대국·영구 기보·학습/MCTS·자체 수신기·GUI 개선은 이 첫 작업에 일괄 포함하지 않는다. 새 명령/설정은 구현 후 실제 검증해 기록한다.

# 승인 기록과 남은 결정

갱신일: 2026-10-28. 파일명은 기존 링크 호환을 위해 유지한다. 현재 목표/우선순위는 아래를 따르고, 이전 승인 원문은 [2026-10-24까지의 승인](history/approvals-through-2026-10-24.md)·[과거 지침](history/agents-through-2026-10-24.md)에 보존한다. 과거 단계의 구현 제외를 현재 목표의 금지로 사용하지 않는다.

## 2026-10-28 확정 목표와 이번 범위

사용자가 확정한 최종 목표:

> 지도학습과 강화학습을 기반으로 강력한 자체 오목 AI를 개발하고, 최종적으로 Gomocup에서 실행·대국할 수 있는 독립 엔진으로 완성한다.

| 항목 | 현재 유효한 결정 |
|---|---|
| 주 산출물 | 자체 학습 모델과 탐색을 사용하는 독립 Gomocup 제출 엔진·소스/모델/실행 파일·검증 자료 |
| 기존 시스템의 역할 | 상태/규칙/오프닝/match는 학습·자동 대국·평가 기반, GUI는 관찰/분석 보조 |
| 우선순위 | 규칙 정확성 → 자동 대국/데이터 → 지도학습 → 탐색 결합 → 자기 대국 강화학습 → 평가/제출 검증 |
| 초기 프로토콜 | 자체 엔진 수신의 최소 동작을 초기에 확인하고 계속 회귀. 외부 Rapfi 제어와 별개 |
| 현재 작업 승인 | 지침/README/계획/승인/인계 등 문서 정리만. 학습·새 기능·대규모 재구성은 시작하지 않음 |
| 순서 제한 갱신 | GUI/사람용 편의 기능·클린 Windows GUI 배포·외부 연동 전체 완료를 자체 AI의 필수 선행 조건으로 두지 않음 |
| 언어/환경 | 기존 C++20 유지. 학습은 Python 등 별도 언어 가능. 프레임워크/추론/장비/모델/탐색은 별도 검토 |
| 알고리즘 후보 | 정책·가치 모델과 MCTS 우선 검토. 채택/구조/예산 확정 아님 |
| 데이터/기보 | 저장/변환은 데이터 기반 기능, GUI 복기는 보조 기능. 출처/이용 조건·규칙/오프닝/종료 사유·계보/분할 버전 보존 |
| 학습/평가 | 지도학습 초기 모델 후 자기 대국 중심 경험/보상/업데이트. 외부 엔진 대국만은 평가이며 보류 평가 조건을 유지 |
| 규칙/대회 | 15×15 렌주 잠정 유지, 참가 연도/리그 미정. 당시 잠정 프로필과 학습 프로필 분리 계획 |
| 제출 작업 | 패키지·검증·안내를 준비하되 공식 대상 확인 전 적합성 미완료. 실제 등록/서명/외부 업로드는 이번 범위 밖 |

## 기존 승인과의 관계

| 이전 결정 | 현재 해석 |
|---|---|
| 자체 AI는 게임/외부 연동 전체 완료 후 별도 단계 | 이번 목표/우선순위가 대체. 필요한 규칙·자동 대국 기반을 검증해 단계별 착수하며 모든 GUI 완료를 기다리지 않음 |
| 신경망/강화학습/실력 향상 제외 | 당시 개별 작업의 범위 제한. 현재 최종 목표에 포함하되 이번 문서 작업에서 구현하지 않음 |
| 첫 버전 기보 저장/불러오기/복기 | 기능 승인 보존. 데이터 저장/변환은 학습 기반으로 우선 배치, GUI 복기는 별도 보조 작업 |
| 사람용 별도 연습 제한 완화 제외 | 기존 GUI 정책 보존. 새 학습 실행 프로필은 별도로 설계/검증하며 대회 준수나 GUI 연습 설정 승인으로 혼동하지 않음 |
| 기본 Gomocup 대회 설정 | 2026-10-19~23 조사한 렌주 일반 잠정 프로필. 전체 학습/모든 대회 공통 상수나 최종 참가 리그 선정이 아님 |
| SWAP2BOARD 지원 | 기존 별도 호환성 요구 유지. 목표 리그의 필수 여부와 분리, Swap2+렌주 자동 결합 금지 |

유지하는 기존 기능/정책: 로컬 사람 대 사람·사람 대 AI·AI 대 AI 지원 목표, Windows10/11 x64 GUI·압축 해제 배포, 금수 표시 기본 켬·클릭 즉시 확정·기권/재시작, 무르기/온라인 제외, 관전 일시정지의 다음 요청 경계, 외부 엔진 시작 실패와 대국 오류 구분/별도 재시도 없음, 심판 충돌 중단·로그·결과 미확정, 기존 매니저 검증용 활용 허용과 선정/연동 요구. DirectRenju의 빈 보드 시작과 PreparedRenju/Swap2 분리도 보존한다. 이 기능들이 전부 구현/검증 완료됐다는 뜻은 아니다.

## 잠정 프로필과 실제 구현 제약

당시 조사한 일반 렌주 프로필은 15×15·RIF 기반 판정·전문가 준비 오프닝·패스 금지·준비 포함200수, 한 수30초/전체180초·메모리1GB·한 CPU 코어·pondering 금지다. [공식 자료를 포함한 당시 조사](compatibility-research.md)를 따른다. 현재 evaluate에는200수가 고정돼 있고 GUI/Rapfi 어댑터에도 제한이 들어 있다. 프로필 분리는 계획이며 이번 문서로 코드 동작을 바꾸지 않았다. 최종 대상 공고를 확인해 범위/단위를 갱신해야 한다.

## 남은 결정과 확인 시점

| 미정 사항 | 결정/검증 시점과 근거 |
|---|---|
| 목표 참가 연도/리그·서버/CPU 환경 | 제출 계획 구체화 시 사용자와 선정, 공식 공고/심판 버전·규칙/확장 명령/자원/패키지 조건 확인 |
| 학습 장비·언어/프레임워크·추론 런타임 | 초기 모델 착수 전 연동/성능/배포/라이선스 비교. Python 허용은 특정 패키지·GPU 승인과 다름 |
| 모델/입출력·정책/가치·탐색/예산 | 지도학습/탐색 단계에서 데이터·기준선·추론 비용에 근거. MCTS는 후보 |
| 데이터 출처/버전·학습/파생모델/재배포 권리 | 취득/학습/공개 전 개별 확인. 공식 준비 오프닝은 아직 미확보 |
| 기보/경험 형식·저장 수단·전처리/분할 | 데이터 기반 단계에서 순서/오프닝/결과·권리·대국 그룹 누출 검사를 포함해 결정 |
| 학습 프로필·보상/기권/오류 대국 처리 | 자기 대국/라벨 사용 전 결정. 시간 초과/프로세스 오류/취소를 정상 승패 보상으로 자동 혼합하지 않음 |
| 평가 상대/보류 배치·표본/승격 기준 | 학습에 쓴 상대/배치와 분리하고 자원/흑백 조건·불확실성에 근거해 결정 |
| 기존 매니저 채택/버전·연결/사용 조건 | 자동 평가/제출 검증 때 [후보 조사](integration-candidates.md)의 문서 지원과 실제 연동 구분. 외부 실행만으로 채택 완료 아님 |
| Swap2 규칙 바인딩·대상 명령 필수 여부 | 해당 호환성 단계에서 근거 확인. 현재 RuleContractRequired 차단 유지 |
| 프로젝트/자체 모델 공개 라이선스·대용량 저장/배포 | 공개/배포 전에 선정. 기존 제3자 코드/모델 조건과 구분 |

기술 선택은 승인 범위에서 개발자가 근거를 남겨 결정하고, 제품 범위/규칙 변경·필수 요구 포기는 확인을 받는다. 미정 항목을 이번에 모두 질문하거나 임의 확정하지 않는다. [개발 계획의 다음 작업 하나](development-plan.md)는 제안이며 별도 구현 요청 전 시작하지 않는다.

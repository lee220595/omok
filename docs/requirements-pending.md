# 승인 기록·설계 결정·미정 목록

갱신일: 2026-10-28. 목표/우선순위는 [AGENTS](../AGENTS.md), 현재 작업 범위는 [인계](handoff.md)를 따른다. [과거 승인 원문](history/approvals-through-2026-10-24.md)·[과거 지침](history/agents-through-2026-10-24.md)과 이후 문서 커밋 e803893/dee8186을 보존한다. 과거 개별 작업 제외를 현재 목표의 금지로 해석하지 않는다.

## 확정 방향

> 지도학습과 강화학습으로 강력한 자체 오목 AI를 개발하고, Gomocup에서 실행·대국할 수 있는 독립 엔진으로 완성한다.

주 산출물은 자체 학습 모델과 추론/MCTS 엔진·소스/실행 파일·재현 가능한 검증 자료다. 기본 경로는 정책·가치 신경망 지도학습 → 저장 모델 실제 대국/기본 엔진 응답 → MCTS → 자기 대국 강화학습이다. 학습 환경과 제출 엔진은 분리하며 C++20 기반을 유지하되 학습 Python/도구는 별도 검토한다. GUI는 관찰/분석 보조이고 전체 편의/클린 GUI 배포·리그와 무관한 Swap2 미완료를 전체 학습 개발 관문으로 삼지 않는다.

Rapfi는 중간/최종 평가 전용 고정 벤치마크다. 현재 학습 상대나 정답 생성 교사로 쓰지 않는다. 이전 자체 모델/단순 기준/Rapfi/후기 다른 엔진의 역할·개발 반복/최종 미사용 평가를 구분한다. AI 자체는 최소 구조부터 실험으로 발전시키되 공통 입출력/체크포인트/데이터/추론 계약은 필수다. AI 외 기능의 작은 확장/교체 경계·버전/호환·프로필/회귀 원칙을 유지한다.

현재15×15 렌주 잠정 기준과 당시2026 일반 렌주 조사 프로필은 [규칙](rules-spec.md)·[조사](compatibility-research.md)를 따른다. 목표 참가 연도/리그는 미정이다. PreparedRenju/DirectRenju/별도 Swap2, 기존 GUI 기능/배포·금수패/외부 엔진 오류·무재시도·판정 충돌 중단/결과 미확정·기존 매니저 활용 요구는 보존한다. 기존 상태/기능이나 미검증을 이번 문서로 바꾸지 않는다.

## 승인 변경의 이력

- 게임/외부 연동 전체 완료 후 자체 AI 착수와 신경망/RL 제외는 당시 작업 제한이었다. 2026-10-28 최종 목표가 갱신했다.
- 초기 문서의 정책·가치/MCTS 후보·외부 보조 교사 가능성은 후속 지시로 기본 경로/Rapfi 평가 전용으로 구체화됐다.
- 이번 계약 보완은 ‘실패 요청 전체 보존’의 범위를 구조적 거부로 한정하고 기존 금수패 적용을 명확히 한 것이다. 금수를 재시도로 바꾸거나 코드 판정을 바꾸지 않았다.
- 현재 특정 작업의 ‘문서만’ 승인 범위는 인계에 기록한다. AGENTS에는 매 작업 최신 요청/승인 범위를 확인하는 지속 원칙을 둔다.
